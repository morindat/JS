# JS

JavaScript fundamentals and small browser projects, written as learning notes.

## Layout

- `BASICS/` — language fundamentals: arrays, objects, classes, inheritance, error
  handling, and array methods (`map`, `find`)
- `BASICS/*.html` — small DOM exercises, including a todo list, a menu page and a
  Git cheat-sheet page
- `NODE/` — Node.js basics

## Run

Browser exercises — open the relevant `.html` file directly.

Plain Node scripts:

```sh
node BASICS/app.js
```

## Stack

Vanilla JavaScript (ES6+), HTML and CSS, with a little Node.js.
